화면별 검토

화면 카드를 여러 개 선택해 개발 완료로 바꿀 수 있습니다. 검토 이력은 이 브라우저에만 저장됩니다.

기본 검토 목록

resources 폴더에 등록된 JSON을 여러 개 선택해 브라우저의 검토 목록으로 불러옵니다. 기존 검토 이력은 유지됩니다.

검토 기록

검토 목록은 feature와 version을 기준으로 구분합니다. 같은 기준의 JSON을 가져오면 검토 목록을 덮어쓸 수 있습니다.

프로젝트에서 npx.cmd expo start --web --port 8091 실행 후 각 화면의 ‘앱 화면 열기’를 사용하세요. 상세·이력·신고 링크는 초기 목업의 헬리오시티 매물을 엽니다. 이 명세 파일은 더블클릭으로 열 수 있습니다.

현재 구현 범위

도식 지도와 시연용 가격·주소를 사용합니다. 앱의 목업 저장 내용은 새로고침하면 초기화됩니다. 이 문서에 작성한 피드백의 임시 보관은 앱 목업 데이터와 별도로 유지됩니다.
검색·지도→필터→상세→관심·저장 조건가격 이력직접 등록신고

모든 화면에서 확인할 사항

  • 최초 로딩은 스켈레톤, 최초 조회 실패는 오류와 재시도를 표시합니다.
  • 캐시가 있는 재조회 실패는 안내와 기존 데이터를 함께 표시합니다.
  • 저장 중 중복 제출을 막고, 실패 시 입력과 저장된 데이터를 유지합니다.
  • 한국어·영어와 시스템 밝은·어두운 모드에 대응합니다.
  • 등록·신고·필터 폼은 공통 입력 오류와 하단 버튼을 사용합니다.
  • 탐색 → 상세 → 뒤로가기에서 검색 조건·지도 위치·목록 위치를 확인하세요.

추후 연동 범위

  • 실제 매물 API, 인증 사용자, 서버 영속 저장
  • 실제 지도 SDK·주소 검색·사진·페이지네이션·마커 클러스터
  • 임장 일정 등록·운영자 신고 처리·결과 알림
  • 실기기 키보드·제스처·safe area·접근성 확인
